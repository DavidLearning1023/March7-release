# March7 使用手册（文字版）

完整图文版是[用户手册](../用户手册.html)——拿到测试包后，双击解压目录里的 `用户手册.html` 即可离线阅读。本文件是同一套流程的纯文字版，适合在终端里看或复制命令。安装细节见[安装指引](ONBOARDING.md)。

## 1. 安装

用 Windows x64 或 macOS Apple Silicon 解压测试包，按[安装指引](ONBOARDING.md)确认平台状态，完成准备、安装和首次信任。

装不上时先看 `uv run python scripts/doctor.py --preflight` 报的缺项和可用空间，再对照安装指引末尾的症状表。

## 2. 更换模型密钥

WorkBuddy 用户按[安装指引](ONBOARDING.md)重跑 `--set-llm`，测试通过后完全退出并重启。多宿主用户还要按各自的接入说明刷新配置：Codex 的工具配置和自动写入所用的进程环境需要分别对齐，DeepSeek Harness 通过重新应用对应的插件配置更新。

不要把宿主配置文件或密钥附在反馈里。

- Codex 交接与配置信息：属研发材料，不随包分发；需要时按 `hosts/codex/install.py` 的提示逐项配置。
- [DeepSeek Harness 接入](../hosts/dsh/README.md)
- [数据与密钥说明](../SECURITY.md)

## 3. 日常怎么用

在已接入的聊天里说「帮我记住，我用蓝册记录演练步骤」，再说「帮我查一下蓝册」。查看回复里的实际补记结果、匹配条目和原话。换到另一个助手时，使用同一库、同一项目再查一次。详见[换工具接力](../用户手册.html#differ)与[记下和找回](../用户手册.html#talk)。

在已接入的宿主里说「打开 March7 记忆面板」，或双击绑定的数据目录中与记忆库同放的「March7 记忆面板」快捷入口。面板打开绑定的库，可以按个人、画像、项目和历史浏览，搜索后点详情核对原话、来源版本和适用期限。「设置与切换库」可打开另一个已有的本机库。会话到期后从原入口重新打开。

测试版不保证回答更准。历史的 324 道合成题评测中，修正后的记忆插件得分为 0.7963，原文基线为 0.9136（该批历史口径，不可与 REAL-30 横比）。见[已知局限](LIMITATIONS.md)。

DSH 桌面 Pi 模式已验证原生操作结果。Codex 若自行启动后看到别的库，先核对库绑定再继续。在终端纠正时，新记录可能缺少 Codex 来源。见[宿主矩阵](HOST-MATRIX.md)。

## 4. 纠错、归档和删除

查找后可以说「把这条改成『我用黄册记录演练步骤』」「把这条记忆归档」或「还原刚才那条」。出现同名候选时，可以说「把第二条改成……」，也可以报出能区分它的文字。纠正保留旧版历史。

说「忘掉这条」会先显示永久删除预览。在同一聊天核对条目和作用域后，可另发「确认删除」或「取消删除」。明确要求永久删除唯一目标时，这句话本身就是授权。换了聊天或项目、提了别的请求、预览过期或条目发生变化时，请重新查找。若宿主无法识别请求，可打开记忆面板续办。

在面板查看详情，可纠正、归档、恢复或永久擦除单条记忆。纠正使用你这次输入的新事实，旧版原话留在历史中。设置可分别关掉纠正和永久擦除的二次提醒，点击对应操作仍是提交动作。归档后的记忆可从历史恢复，永久擦除无法撤销。

## 5. 体检与批量整理

说「看看个人记忆有没有重复」或「帮我整理当前项目的记忆」，宿主会先检查并拟一份草稿。看过条目和草稿编号后，在同一聊天回复，例如「按这个方案执行 M7-……」或「取消这份方案 M7-……」。可以明确指定保留或归档哪些条目。

整理会保留原话、来源和历史。已执行后可让助手根据回执生成撤销预览；面板里也能核对与管理。自动体检默认关闭，可按范围开启。详见[体检与批量整理](../用户手册.html#talk)。

## 6. 导出、回执与停止使用

说「查看擦除回执」「看看记忆库现在怎么样」或「导出我的记忆」。回执记录范围、计数与验证状态，不含擦除正文。在面板也可核对回执。旧导出、备份、宿主原对话和模型服务商留存需要按各自位置核对。

终端兼容命令见[记忆管理](../用户手册.html#panel)。卸载用 `hosts/workbuddy/install.py --uninstall`（只移除它自己写的，不动记忆库）；确认不再需要数据后，用 `uv run python -m March7.control erase --all` 删除。

## 7. 装不上怎么办

优先检查系统、首次信任、完全重启和数据目录。能连接但写入失败时，运行 `uv run python -m March7.control why --last`。

在聊天里可以说「当前库和项目」「为什么没记住」或「为什么用了这条记忆」。也可以在本机面板打开「记忆诊断」。库编号可以跨宿主对照，诊断还显示项目假名、近期写入或召回结果与预算。恢复会话时若提示工作目录与原项目不同，回到对应目录或新开会话。项目事实缺少身份时，切到正确项目后重新补记。

自动注入会筛掉弱相关和已失效的记忆。没有注入时仍可用更具体的关键词主动查；进入面板历史或明确说「查历史」可核对旧版。诊断显示筛选原因和计数，原话由授权的查找和详情入口提供。
